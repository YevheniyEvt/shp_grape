## v0.1.0 (2026-11-17)

Stage 1 of the MVP: project infrastructure, bilingual groundwork and the base site layout.

### Feat

- project infrastructure, i18n and base site layout:
  - Django 6.1 REST API managed with uv, PostgreSQL 17 in Docker, settings from `.env`
  - `/api/health/` with the deployed version, Swagger docs at `/api/docs/`
  - Ukrainian (default) and English: UI strings in Django `.po` files, served to the frontend
    as a gettext catalog; `makemessages_frontend` extracts strings from the Next.js sources
  - Next.js 16 frontend: language routing, globe language switcher, header, mobile menu,
    footer, section placeholders, localized 404, vineyard colour theme
  - pytest and Vitest suites, `justfile`, pre-commit hooks, GitHub Actions CI

### Fix

- **i18n**: translation catalogs list source files without line numbers, so reformatting
  code no longer makes them stale
