## v0.2.0 (2026-11-18)

Stage 2 of the MVP: the catalog backend, with grape varieties, the admin to manage them and the REST API for the site.

### Feat

- **catalog**: add varieties with photos, videos, admin and REST API
  - varieties with characteristics, prices and availability, plus five reference lists filled with default values (uk + en);
  - photos with WebP renditions (400/1000/1800 px), one main photo per variety, YouTube videos;
  - the admin is always in Ukrainian and has language tabs, drag-and-drop photos, bulk photo upload, prices editable in the list and a rich-text editor;
  - `/api/catalog/`: a variety list with every advanced-search filter, typo-tolerant search, ordering and pagination; a variety page with similar varieties; a view counter; filter options; an alphabet; random photos.
- **core**: add automatic slugs, rich-text field and admin helpers
  - slugs are transliterated from the Ukrainian name (KMU 2010) and stay the same when the object is renamed.

### Fix

- **tooling**: keep uv.lock untouched by git hooks and refresh it on bump

## v0.1.0 (2026-11-17)

Stage 1 of the MVP: project infrastructure, bilingual groundwork and the base site layout.

### Feat

- project infrastructure, i18n and base site layout:
  - Django 6.1 REST API managed with uv, PostgreSQL 17 in Docker, settings from `.env`
  - `/api/health/` with the deployed version, Swagger docs at `/api/docs/`
  - Ukrainian (default) and English: UI strings in Django `.po` files, served to the frontend
    as a gettext catalog; `makemessages_frontend` extracts strings from the Next.js sources
  - Next.js 16 frontend: language routing, globe language switcher, header, mobile menu,
    footer, section placeholders, localized 404, vineyard colour theme
  - pytest and Vitest suites, `justfile`, pre-commit hooks, GitHub Actions CI

### Fix

- **i18n**: translation catalogs list source files without line numbers, so reformatting
  code no longer makes them stale
