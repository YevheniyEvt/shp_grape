# Demo photos: sources and licences

`manage.py seed_demo` takes the photos of a demo variety from `photos/<variety-slug>/`
(`.jpg`, `.jpeg`, `.png`, `.webp`, sorted by file name; the first one becomes the main photo).
A variety without a folder gets generated placeholder pictures.

Only own photos or images under a free licence (Unsplash, Pexels, CC0) may be added here.
Never use photos from the reference site. List every added file below.

Demo variety slugs: `rankovyi-ametyst`, `burshtynova-zoria`, `stepovyi-rubin`, `nichnyi-sapfir`,
`bilyi-tuman` (the last one intentionally has no photos).
